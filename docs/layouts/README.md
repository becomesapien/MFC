# Hotbar layouts

Layout rules and most placements by Fr4nsson (FFC); PvE controller layouts originally by Squintina; Dawntrail and PvP updates by Megumax.

Generated directly from the shipped `HOTBAR.DAT` using the shipped keybinds. **Visual note:** in-game the 4×3 blocks show the plain row on top, then SHIFT, then CTRL (see the main README).

**Controller labels:** each cross hotbar has 16 slots — LT d-pad 1-4, LT buttons 1-4, RT d-pad 1-4, RT buttons 1-4 — numbered in the same order the game lists them under *Character Configuration → Hotbar Settings → Cross Hotbar* and in HUD Layout.
